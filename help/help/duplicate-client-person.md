## Clients

"A client with this name already exists" means the exact name is taken. Search first ([Find a client](help:clients/find-a-client)). If two clients were created with slightly different spellings, keep the one with the cases. A Manager can delete the empty one (only if it has no cases).

## People

The app matches people **by name** when importing or applying Smart fill. A different spelling (for example "Ali O. Kazi" and "Ali Omari Kazi") makes a second person.

1. Open the company's **Company** tab.
2. Keep the card with the full details and correct name.
3. Delete the other card.
4. Generate documents again so names are consistent.

> Use full names exactly as on the BRELA register to avoid duplicates.
