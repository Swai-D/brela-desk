| Message | Fix |
|---|---|
| "Choose a file" | Nothing was selected; select a file first |
| "Only image files (JPG, PNG, WebP)" | Photos to PDF accepts images only |
| "Only a PDF can be replaced by a PDF" / "The result must be a PDF" | Replacing a PDF needs a PDF result |
| "Choose a picture" | Choose an image for the profile picture (under 3 MB) |
| "The signature must be a PNG image" | Save or upload the signature as PNG |
| "Use a .docx file" / "Choose a Word (.docx) file" | Save the file as .docx in Word |
| "Too many requests. Slow down a little." | Wait a minute and try again |
| The file is over 15 MB | See [File too big](help:help/file-too-big) |

## General checks

1. Check your internet connection and try again.
2. Refresh the page (**Ctrl+F5**); if the app was locked you may need to sign in again.
3. Try another browser if a file will not open.

See also: [Checklist and files](help:cases/checklist-and-files).
