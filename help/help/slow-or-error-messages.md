---
title: Error messages and what they mean
summary: A list of the messages the app shows and the fix for each.
keywords: error, server error, message, not found, too many requests, session, 401, 403, 404, 429, permission, failed, try again, something went wrong
order: 10
---
| Message | Meaning and fix |
|---|---|
| "Wrong email or password" | [Cannot sign in](help:help/cannot-sign-in) |
| "Too many attempts. Try again in 10 minutes." | Wait |
| "Too many requests. Slow down a little." | Too many clicks per minute; wait a minute |
| "Only a Senior or Manager can do this step." / "…can rename…" | Needs a higher level ([Roles](help:getting-started/roles-and-access)) |
| "Only a Manager can change the client or case type" | Manager only |
| "Only the uploader, a Senior or a Manager can delete this" | Ask one of them |
| "You can edit only your own comments" / "…delete only your own comments" | Comments belong to their author (a Manager can delete any) |
| "You can open this only while an open case of this client is assigned to you" | Vault access rule ([Vault](help:clients/vault)) |
| "Complete all documents in the checklist first." | [Case cannot move](help:help/case-cannot-move-stage) |
| "Write what BRELA asked to correct." | Add the reason |
| "Client not found" / "Case not found" / "Template not found" / "Not found" | The item was deleted or you followed an old link; refresh |
| "Already filed or not found" | Someone already filed that Inbox file |
| "This client has cases. Delete or move those cases first." | Delete rule ([Add a client](help:clients/add-a-client)) |
| "Cases already use this type. Hide it instead." | [Case types](help:settings/case-types) |
| "This person has work history. Deactivate them instead" | [Team](help:settings/team-and-roles) |
| "At least one active Manager must remain" | Keep a Manager |
| "The AI is not set up yet…" / "Your role is not allowed to use the AI" | [AI settings](help:settings/ai-settings) |
| "Server error" | A fault in the app. Refresh and try again; if it repeats, note the page, what you pressed and the time and tell the person who looks after the app ([Still stuck?](help:help/contact)) |

If a page is blank or buttons do nothing, refresh with **Ctrl+F5** and sign in again.
