| Problem | Fix |
|---|---|
| "Paste the BRELA Company Details page first" | The box was empty. Paste the text. |
| Preview is empty or very small | Copy the whole page (Ctrl+A on the BRELA page), not a part, and paste again |
| Some people are missing | The page lists people in separate sections; make sure you copied below them too. Add the missing person by hand ([People](help:clients/people)). |
| "No activity is marked as Main" | Pick the main activity yourself in the company fields after applying |
| The address looks odd | Surveyed and unsurveyed addresses are read differently; edit the person or company address parts |
| Import created a duplicate | People are matched by name; a different spelling creates a new person. Delete the duplicate ([Duplicates](help:help/duplicate-client-person)) |
| You pressed Apply by mistake | Edit the values back; typed values are kept on later imports unless BRELA provides them |

## Reminder

Nothing is saved until you press **Apply**. Read the preview and the warnings first.

See also: [Import from BRELA](help:clients/import-from-brela).
