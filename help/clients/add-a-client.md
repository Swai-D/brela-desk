---
title: Add a client
summary: Create a client and keep their contact details.
keywords: new client, create client, phone, email, whatsapp number
order: 1
---
1. Open **Clients** and press **New client**.
2. Type the name and the phone number. Use the WhatsApp number with the country code, for example `2557…`, so incoming WhatsApp documents find the client.
3. Save. The client page opens with the **Company** tab, the people, the cases and the vault.

> Only a Senior or Manager can rename a client. A Manager can delete a client, only if the client has no cases.
