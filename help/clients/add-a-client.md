## Add a client

1. Open **Clients** and press **New client**.
2. Fill in:
   - **Name** (required): the company or person's name.
   - **Phone**: the WhatsApp number. Write it as `0712 345 678` or with the country code `255712345678`. Without 0 or the code, files they send cannot be matched to them.
   - **Email**.
   - **BRELA track number**: optional.
3. Press **Save**. The client page opens.

A client with the same name cannot be created twice: "A client with this name already exists." Find the existing one with the search box instead.

You can also type a new client's name in the **Client** box when creating a case; the app creates the client for you.

## Edit contact details

On the client page press **Edit**. Phone, email and track number can be changed by anybody. The **name** can be changed only by a **Senior** or **Manager** (the box is greyed out otherwise: "Only a Senior or Manager can rename a client").

## Delete a client

Only a **Manager** can delete a client, and only if the client has **no cases**: "This client has cases. Delete or move those cases first." Deleting also removes the client's documents and saved logins and cannot be undone. The audit log records it.

> Prefer fixing a wrong name to deleting a client. Deleting is for clients created by mistake.
