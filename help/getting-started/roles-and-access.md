A **role** is a job in your team (Manager, Senior, Secretary, Junior, Associate or any role the Manager creates). A Manager decides what each role can do by ticking permissions in **Settings → Team & roles → Roles & access** ([how](help:settings/roles-and-access-levels)). Staff, Senior and Manager are the starting sets of ticks. The table below shows what those starting sets allow. Your own role may have more or fewer ticks: the Playbook tab **My role** lists what you can and cannot do.

## What the starting sets allow

| Action | Staff | Senior | Manager |
|---|---|---|---|
| Create clients and cases, upload and preview documents, comment | ✓ | ✓ | ✓ |
| Prepare documents and wizards, fill templates, use Doc Studio | ✓ | ✓ | ✓ |
| File documents from the WhatsApp Inbox | ✓ | ✓ | ✓ |
| Tick the guide steps on any case | ✓ | ✓ | ✓ |
| Open a client's vault | only while an open case of that client is assigned to them | ✓ | ✓ |
| Submit to BRELA, record BRELA's answer (Submitted, Returned, Completed) | | ✓ | ✓ |
| Change a case's assignee and due date | | ✓ | ✓ |
| Rename a client, rename or remove checklist items | | ✓ | ✓ |
| Rename or delete any file (others: only your own uploads) | | ✓ | ✓ |
| Add, edit, delete vault logins | | ✓ | ✓ |
| Create, edit, approve and teach document templates | | ✓ | ✓ |
| Use the AI assistant | ✓ | ✓ | ✓ |
| Settings (team, case types, roles, WhatsApp, AI), Reports, audit log, Playbook texts | | | ✓ |
| Change a case's client or type, delete a case, delete a client | | | ✓ |
| Edit the document wizards | | | ✓ |

## Good to know

- Changes take effect immediately. When a Manager changes your role, you do not need to sign out.
- You can always see what your role allows in the Playbook under **My role**.
- Buttons you cannot use are hidden or the app answers with a clear message such as "Only a Senior or Manager can do this step."
