The **Documents** card is the list of everything the case needs. A case can move forward only when every item is ticked.

## Work an item

- **Tick** the checkbox when the document is ready. It also ticks automatically when you upload a file.
- **Upload:** press the upload icon on the item and choose files (several allowed, **15 MB each**).
- **Preview:** click a file name. Word and PDF open inside the page.
- **Photos to PDF:** the picture icon opens Doc Studio to turn phone photos into one PDF and attach it to the item ([Photos to PDF](help:studio/photos-to-pdf)).
- **Prepare a document:** the robot icon fills a document from a template ([Fill a template on a case](help:documents/fill-a-template-on-a-case)).

## Change the list

| Action | How | Who |
|---|---|---|
| Add an item | Type in "Add a document item (e.g. Lease agreement)" and press +. | Everyone |
| Rename an item | The pencil on the item | Senior, Manager |
| Remove an item and its files | The bin on the item | Senior, Manager |
| Add the documents of another change | **Add another change** ([Create a case](help:cases/create-a-case)) | Everyone |

Items are grouped by change when the case has choices (for example one group per change).

## Files

- Rename, replace or delete a file: the uploader, a Senior or a Manager. Others see "Only the uploader, a Senior or a Manager can delete this".
- A PDF can be replaced only by a PDF ("Only a PDF can be replaced by a PDF").
- Deleting cannot be undone and is written to the [audit log](help:settings/audit-log).

## Files made by the app

Documents made by [Prepare documents](help:documents/prepare-documents) are attached automatically. When the case has an item with the form number in its name (for example "Form 213a"), the file is linked to it.
