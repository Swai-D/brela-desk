## Steps

1. Press **New case**: on the Dashboard, My Work, the Case Board or a client page (there the client is already filled in).
2. **Client:** type or pick. If the name is new, the client is created for you.
3. **Case type:** pick one. The list shows the types your Manager keeps active.
4. Some types ask **What kind of change?** Tick all that apply, and for each choose what to do (for example **Directors: Add, Remove**). If you tick a change but choose no action: "Choose what to do for Directors: …".
5. **Assign to:** defaults to you. Pick a colleague if needed.
6. **Due date:** optional but recommended; it drives the overdue alerts.
7. Press **Create case**. The case opens.

## What is created

- A **checklist of documents** copied from the case type (plus the documents of the changes you ticked).
- The stage **New**.
- A history entry, and a WhatsApp alert to the assignee when it is not you.

## Add another change later

On a case made from a type with choices, press **Add another change** above the checklist, tick what else the client needs, and press **Add to this case**. Only new document items are added; nothing already on the case changes ([Checklist and files](help:cases/checklist-and-files)).

## Mistakes and fixes

| Problem | Fix |
|---|---|
| "Pick a case type" | Choose a type |
| "Choose what kind of change this is" | Tick at least one choice for types with choices |
| Wrong client or type | A Manager edits it ([Edit a case](help:cases/edit-a-case)); note the checklist does not change |
| The type you need is missing | Ask a Manager to add or unhide it in [Case types](help:settings/case-types) |
