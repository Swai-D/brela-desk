Open a case from the board, My Work, a client page or search.

## The header

Client name (opens the client), the case code, the case type, the stage badge and **BRELA round N** if it was returned. Below:

- **Assigned to**, **Due** (with how late), **Documents** (for example 3 of 5 ready).
- **BRELA track number:** type it after submitting and press the check button. The app warns if another case uses the same number.
- A **stepper** with the six stages; finished stages show ✓.
- **Ask about this case**: a chat about this case and its documents ([Ask about this case](help:cases/ask-about-this-case)).
- **Edit case** (needs the matching permission) ([Edit a case](help:cases/edit-a-case)).
- If BRELA returned the case, a red band shows the reason.

| Card | Purpose | Guide |

## Right column

| Card | Purpose | Guide |
|---|---|---|
| **What to do now** | Stage, who is responsible, steps, **Done when** and the stage button. Also **Notes for <case type>** from Settings. | [How a case flows](help:getting-started/how-a-case-flows) |
| **Prepare documents** | Wizards that fill the official forms | [Prepare documents](help:documents/prepare-documents) |
| **Details for documents** | Facts specific to this case, **Smart fill** | [Case details](help:cases/case-details-for-documents) |
| **BRELA rounds** | How many returns and the last reason | [Submit and track](help:cases/submit-and-track) |
| **Client vault** | The client's logins, reveal with the lock button | [Vault](help:clients/vault) |
| **History** | Every action on the case, with who and when | [History](help:cases/history) |

> Tip: the code in the header (for example the case code) is what Managers type to confirm deleting a case.
