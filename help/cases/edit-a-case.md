The **Edit case** button is in the case header. It is visible to Seniors and Managers.

## What can be changed

| Field | Who |
|---|---|
| **Assign to** | Senior, Manager |
| **Due date** | Senior, Manager |
| **Client** | Manager only: "Only a Manager can change the client or case type" |
| **Case type** | Manager only. The checklist does **not** change when the type changes. |

Reassigning sends the new person a WhatsApp alert and puts the case in their **My Work**.

## Delete a case (Manager)

1. Press **Edit case**, then **Delete**.
2. Confirm. The app asks you to type the case code to avoid mistakes.
3. The case, its documents, comments and history are removed **permanently** and recorded in the audit log.

> Almost always better: complete the case, or leave a comment. Delete only cases created by mistake.

See also: [My Work](help:daily-work/my-work), [Roles and access](help:getting-started/roles-and-access).
