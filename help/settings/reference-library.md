BRELA judges applications against the **Companies Act**. The reference library holds the Act, and any guides, so that the [case chat](help:cases/ask-about-this-case) checks every case against them and names the section. You add each document once; it then applies to every case.

You need the permission **Add, change and remove the reference library (the Companies Act and guides)**. Open **Settings → Reference library**.

## Add a document

1. Press **Add document**.
2. **Name**, for example "Companies Act 2002".
3. **Type**: **Law** (the Act and its amendments) or **Guide** (BRELA forms, notices, practice).
4. **File**: a PDF with real text is best; Word, text, and scans are also accepted. A scan is read with text recognition, which can take a minute for a long document, and the list then says "read by text recognition, so check it".
5. Press **Add**. The app tells you how many sections it found. A very low number means the file did not read well: try a better copy.

Use the official, current text including amendments. The assistant treats this text as the law and does not quote the law from memory.

## Switch off, rename, remove

- **In every chat** switch: off keeps the document but the chat stops using it.
- The pencil renames it; the bin removes it (case chats stop using it at once).
- Every change is written to the [audit log](help:settings/audit-log).

## What happens in a case

For each question the chat picks the sections that match your words and what BRELA last asked to correct, then answers with the section named, for example "Section 5". If the library does not cover a point, it says so.

See also: [Ask about this case](help:cases/ask-about-this-case), [AI settings](help:settings/ai-settings).
