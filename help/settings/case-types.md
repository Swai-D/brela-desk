**Settings → Case types** decides which documents each kind of case needs. New cases copy the checklist of their type.

- **Add case type**, rename it, edit the list (one document per line), or hide it. A type that cases use cannot be deleted; hide it instead.
- For **Change of Particulars** the choices (company name, registered office, directors and so on) and their documents are editable too.
- **Notes** appear on every case of that type, for example BRELA portal tips.
