**Settings → Case types** decides the checklist every new case receives.

## Add or edit a type

1. Press **Add case type** (or the pencil on a row).
2. **Case type name**.
3. **Document checklist**: one document per line. New cases copy this list.
4. **Notes for the team**: tips shown on every case of this type under "Notes for <type>" (for example BRELA portal steps).
5. **Choices** (optional): see below.
6. Save.

## Choices and actions

Use choices when one type covers several kinds of change, like **Change of Particulars** (company name, registered office, directors…).

1. Press **Add a choice** and name it (for example Registered office).
2. In its box list the documents for that choice, one per line.
3. Press **Add actions (like Add / Remove / Update)** to add actions such as Add or Remove, each with its own documents.

When someone creates a case they tick what applies, and only those documents are added ([Create a case](help:cases/create-a-case)).

## Hide, show, delete

- The eye toggles whether the type appears in **New case**.
- **Delete** works only if no case uses the type ("Cases already use this type. Hide it instead.").
- Changing a type's checklist does **not** change cases already created.

> Keep the checklist short and exact; every item must be ticked before a case can be submitted.

Messages: "A case type with this name already exists", "Name required".
