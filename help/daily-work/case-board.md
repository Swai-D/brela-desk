The **Case Board** shows every case as a card in the column of its stage: **New**, **Gathering Docs**, **Ready to Submit**, **Submitted to BRELA**, **Returned (Correction)** and **Completed**.

## Reading a card

- The **client name** opens the case.
- Under it: the case type, the case code, the BRELA track number (with #) if saved, and **BRELA round N** if BRELA returned it before.
- A returned card shows BRELA's reason in red.
- At the bottom: documents ready (for example 3/5 with a bar), the due date (**Today**, a date, or **Nd late** in red) and the person it is assigned to.
- A column header shows how many cases are in it and, in red, how many are late.

## Filters and search

| Control | What it does |
|---|---|
| **All assignees** menu | Shows only one person's cases |
| Search box | Matches client, case code, type and track number |
| **All / Mine / Late / Returned** buttons | Everyone's cases, only yours, only overdue, only returned |

Each column shows the first 10 cards; press **Show N more** for the rest. The line under the title says how many cases are shown.

## Move a case by dragging

Drag a card to another column and drop it. The same rules as the buttons on the case page apply:

- All checklist documents must be ticked before **Ready to Submit**, **Submitted** or **Completed**.
- Only a Senior or Manager can drop a card into **Submitted**, **Completed** or **Returned**.
- Dropping into **Returned** opens a box: write what BRELA asked to correct. If you leave it empty the card jumps back.

If the move is refused you see a red message and the card returns to its column.

> On a phone it is easier to open the case and use the stage button.
