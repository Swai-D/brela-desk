The search box in the top bar finds things across the whole app.

## How to use it

1. Click the box and type **at least 2 letters**. Results appear under the box while you type.
2. Move with the **up and down arrow keys**, press **Enter** to open the highlighted result, or click one. **Esc** closes the list.
3. Press **Enter** with nothing highlighted, or the search button, to open the full results page (**search.html**), which lists everything that matches.

You can also search by **incorporation number**; client results show it as **Inc. no.**, and the case page shows it beside the case code.
4. On a phone, use the magnifier icon in the top bar.

## What is searched

| Group | Matched on | Opens |
|---|---|---|
| **Clients** | name, phone, email, BRELA track number | the client page |
| **Cases** | client name, case code, case type, track number | the case |
| **Documents** | file name | the file |
| **Comments** | the comment text | the case |
| **Vault logins** | the label only (never the password) | the client page |

The matching letters are highlighted.

## Tips

- Search a **track number** to find the case or client straight away.
- Search a phone number in the form you saved it (for example `255712…`).
- Searching a word from a comment finds the case where somebody wrote it.
- If you find nothing, try fewer letters, or the other spelling of a name.
