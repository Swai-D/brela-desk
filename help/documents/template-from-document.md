## Steps

1. **Templates → From an accepted document**.
2. Upload a **.docx** file, or a **PDF that has real text** (not a photo), or paste the text.
3. Give the template a name and press the button. The AI marks the parts that change (names, dates, numbers) as fields.
4. Review the text and fields, then save. The template starts as **Draft**.

## Messages

| Message | Meaning |
|---|---|
| "Upload a document or paste its text" | Nothing was provided |
| "The Word file has no text" | The file is empty or an image; paste text instead |
| "Use a .docx file" / "Choose a Word (.docx) file" | Old .doc files are not accepted; save as .docx |
| "This Word file could not be read" | Re-save the file in Word and upload again |
| "The AI is not set up yet…" | A Manager must add the AI key ([AI settings](help:settings/ai-settings)) |

> Photos or scanned PDFs have no text. Type or paste the text instead.
