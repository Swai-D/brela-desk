## Versions

Every time the text changes a new version is saved with your **What changed?** note. **Earlier versions** lists them; **Restore** brings an old one back **as a new version** (nothing is lost). Changing only the name or description does not create a version.

## Replacing the Word file safely

When you press **Upload edited Word** on a template that has a Word form, nothing changes at once. A dialog first shows:

- **These fields will no longer be filled**: fields that were in the old file and are missing from the new one (a broken or deleted yellow label). This is the common mistake, so read it carefully. If the list is not empty, the button reads **Replace anyway**.
- **New fields with no company data yet**: labels that did not exist before. Your own templates get a wizard question for each.
- How many fields stay the same.

Only after you press **Yes, replace** does the new file go live. The file you replaced is kept. Press **Earlier Word files** to see the list (date, who replaced it, number of fields) and **Restore** to use an old file again; the file you restore over is kept too, so nothing is ever lost. Only a Senior or Manager can do this.

Before you replace a template that is in daily use, try the new file on a sample client's case, then replace it.

## Draft, ready to approve, approved

| Status | What it means |
|---|---|
| **Draft** | Needs more checking. Preparing a document may use the AI with the template as a format guide. |
| **Ready to approve** | Three clean runs in a row (no manual edits, no gaps) |
| **Approved** | Fills **instantly with no AI** |

A Senior or Manager presses **Approve** when the template is ready. Editing an approved template sends it **back to draft** and it needs approving again.

## Teach the template

After you correct a generated document, press **Teach the template from my corrected version** (it appears when saving). It turns your final text into an improved template (a new version) so next time the result is right. See [Fill a template on a case](help:documents/fill-a-template-on-a-case).
