## Versions

Every time the text changes a new version is saved with your **What changed?** note. **Earlier versions** lists them; **Restore** brings an old one back **as a new version** (nothing is lost). Changing only the name or description does not create a version.

## Draft, ready to approve, approved

| Status | What it means |
|---|---|
| **Draft** | Needs more checking. Preparing a document may use the AI with the template as a format guide. |
| **Ready to approve** | Three clean runs in a row (no manual edits, no gaps) |
| **Approved** | Fills **instantly with no AI** |

A Senior or Manager presses **Approve** when the template is ready. Editing an approved template sends it **back to draft** and it needs approving again.

## Teach the template

After you correct a generated document, press **Teach the template from my corrected version** (it appears when saving). It turns your final text into an improved template (a new version) so next time the result is right. See [Fill a template on a case](help:documents/fill-a-template-on-a-case).
