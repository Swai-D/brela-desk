## Where AI is used

| Feature | AI? |
|---|---|
| **Prepare documents wizards** | **No.** Fixed rules, same result every time |
| **Import from BRELA** | **No.** Fixed rules |
| Filling an **approved** template | **No** |
| Filling a **draft** template or no template | Yes |
| **Smart fill** from a client's message | Yes |
| Creating a template **from an accepted document** | Yes |
| **Teach the template** | Yes |

## Privacy

ID numbers, phone numbers, emails and dates of birth are never sent. Texts you paste (Smart fill) are sent to the provider named in the dialog; paste only what is needed.

## Cost and control

A Manager chooses the provider, model and limits, and can restrict which roles may use it ([AI settings](help:settings/ai-settings)). Approved templates and wizards cost nothing.

## When the AI is off

You can still do everything except the AI features. Messages: "The AI is not set up yet. A Manager can add an API key in Settings → AI assistant."

> The AI can make mistakes. Always read before saving or signing.
