## Open it

**Templates → New template**, or the pencil on an existing template.

## The fields of the editor

| Part | What to write |
|---|---|
| **Template name** | For example "Memorandum and Articles of Association" |
| **Case type** | Optional. Ties the template to a kind of case |
| **Match words** | Words that suggest this template when a checklist item contains them, for example `memarts articles memorandum` |
| **Description** | A line for the team |
| **Notes for the AI** | BRELA's format rules: layout, clause numbering, wording that must not change (used when the AI helps) |
| **Template text** | The document. Insert details from the **Insert a field** list on the right. |
| **What changed?** | A short note saved with the new version |

## Insert a field

On the right, **Fields in this template** shows the fields already in the text. **Insert a field** lists everything available; use **Search fields** and click a field to put it at the cursor. **No field matches** means the name is unknown ([Template fields](help:documents/template-fields-syntax)).

## Save

Saving creates a new **version** only when the text changed ([Versions](help:documents/template-versions-and-approval)).

> A template made from an official Word file is filled directly from that file. Editing its text does not change the Word file's layout; ask your Manager if the official form changed.
