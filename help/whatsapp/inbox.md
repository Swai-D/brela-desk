When a client sends a file to the office WhatsApp number it appears in **WhatsApp Inbox**. The counter on the menu shows how many wait.

## The page

Four numbers at the top: **waiting to be filed**, **from unknown senders**, **senders**, **oldest file**. Filter with **All / known / unknown** and the search box (file name, sender, phone, client, note).

Each row shows the file, size, age, who sent it and the client it matched (if any).

## File a document

1. Open the row's **File** action; a box titled "File “<file name>”" opens.
2. Choose the **Client** (preselected if the number matched; "Choose a client" otherwise).
3. Choose the **Case** of that client and the **Checklist item**, or **Client folder only**.
4. Confirm. "Document filed ✓". The file leaves the inbox and becomes part of the case or client.

You can also **Open in Studio** to turn photos into a PDF or edit before filing ([Photos to PDF](help:studio/photos-to-pdf)).

## Discard

Press **Discard file** and confirm **Yes, discard**. Use it for spam or duplicates; it cannot be undone.

## Unknown senders

If the phone number does not match any client the row says so. Pick the client yourself when filing. To make the next one match, save the client's number with the country code ([Add a client](help:clients/add-a-client)).

> An empty inbox shows "Inbox is clear". Files are limited to 15 MB; larger ones are not received.
