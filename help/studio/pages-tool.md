Open **Pages**. Each page of the PDF is a thumbnail.

| Control | What it does |
|---|---|
| **Rotate left / right** | Turns one page. **Rotate all** turns every page. |
| **Delete this page** / **Keep this page** | Marks a page **Will be deleted**; press again to keep it |
| **Move earlier / Move later** | Changes the order. You can also drag. |
| **Add a blank page after this one** | Inserts an empty page |

If the page already has your signature or other items, the buttons say **"Remove the items on this page first"**. Remove them, then rotate or delete.

**Nothing changes until you press the save button.** Use **Discard changes** to start over.
